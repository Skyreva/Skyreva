# Valentin Salic

Ingénieur logiciel **C++/Qt & Python**, diplômé de l'[ENSICAEN](https://www.ensicaen.fr/) (majeure Image, Son, IA). Basé à Paris.

Je conçois des applications desktop et des pipelines de vision / IA, de la recherche jusqu'à l'outil utilisable : reconstruction 3D (Gaussian Splatting, COLMAP), APIs Python, conteneurisation Docker. Ce qui m'intéresse, c'est de passer d'un résultat de recherche à un outil que quelqu'un d'autre peut utiliser.

## Projets

- **[OSProject](https://github.com/Skyreva/OSProject)** : simulation d'épidémie en C avec processus séparés, mémoire partagée POSIX, files de messages, signaux et threads (mutex, barrières), interface Python/Pygame. J'ai développé le processus *citizen manager*.
- **Visualiseur 3D de régions d'activation de réseaux de neurones** (laboratoire GREYC, benchmark PINNacle) : C++17, ImGui, OpenGL. Interface d'inspection, statistiques par région, sélection d'une région au clic par lancer de rayon accéléré par BVH.
- **Reconstruction 3D pour simulateur de conduite** (AVSimulation, stage de fin d'études) : comparaison de variantes de Gaussian Splatting, projection de panoramas 360°, application Qt6 pilotant un conteneur Docker GPU.
- **IA générative en vision médicale** : GAN conditionnel en PyTorch.
